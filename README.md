# 🎮 Devine le nombre

Le principe du jeu est simple : l'ordinateur choisit un nombre au hasard entre 1 et 100 et le joueur doit le deviner.

## ✨ Fonctionnalités

- Saisir une valeur entre 1 et 100
- Valider sa réponse en cliquant sur le bouton ou en appuyant sur la touche Entrée
- Obtenir un indice indiquant si le nombre proposé est trop petit ou trop grand
- Afficher un message de victoire lorsque le nombre est trouvé
- Compter le nombre d'essais
- Empêcher de continuer à jouer une fois le nombre trouvé
- Recommencer une nouvelle partie avec un nombre aléatoire

## 🛠️ Technologies utilisées

- HTML
- CSS
- JavaScript

- Manipuler les éléments HTML avec JavaScript
- Utiliser des variables et des conditions
- Générer un nombre aléatoire avec JavaScript
- Réagir aux actions de l'utilisateur avec des événements
- Modifier le contenu d'une page avec JavaScript
- Utiliser le DOM pour interagir avec une page web
- Organiser un projet avec plusieurs fichiers HTML, CSS et JavaScript
- Utiliser Git et GitHub pour versionner et publier mon projet

## 🚀 Lancer le projet

1. Télécharger ou cloner le projet
2. Ouvrir le fichier `index.html` dans un navigateur
3. Commencer à jouer !
